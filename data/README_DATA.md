# Data files

- `wac.epd` - Win At Chess suite, 300 tactical positions (`bm` = book best move(s), `id` = WAC.001 ...).
  Copied from `wacnew.epd` in https://github.com/fsmosca/EPD-Analyzer (GPL-3.0; credit it in the report),
  with Windows line endings converted. Positions are from Reinfeld, _Winning Chess Positions_.
- `real_games.pgn` - the real games positions are sampled from (your own combination of Chessentials
  collections, the McDonnell file and the Croatian championships). Built with the PowerShell
  join script; its game counts are recorded in `project-plan.md`.
- `trigger_model.json` - P(value changes with one more ply | number of checking moves) and the mean size
  of the change. Generated by `analyze_instability.py` from `instability_log.csv`; regenerate it on your
  machine (`log_instability.py`, then `analyze_instability.py`) so the numbers in the report are yours.
- `instability_log.csv` - generated by `log_instability.py` (not committed; it is reproducible).
